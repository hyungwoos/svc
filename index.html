권한 설명 — super_admin: 전체+계정 관리+변경 이력 · admin: 조회+수정 · admin_viewer: 조회만(수정 불가) · poc: PoC·주간회의 메뉴만 · equipment_poc: 장비+PoC+주간회의 메뉴만 · «권한 없음»: 로그인은 되지만 제한 화면만 보입니다

— 메뉴 권한 (계정마다 보기 · 읽기 · 쓰기) —

보기 = 메뉴에 나타나고 화면을 열 수 있음 · 읽기 = 화면 안의 표·데이터 열람 · 쓰기 = 추가·수정·삭제. 쓰기는 읽기를, 읽기는 보기를 포함합니다. 행이 없는(한 번도 저장하지 않은) 계정은 역할 기본값(admin 전부 · admin_viewer 읽기까지)으로 동작하고, 슈퍼 관리자는 제한할 수 없습니다. 바뀐 권한은 그 계정이 다음에 화면을 새로 읽을 때 적용됩니다.

— 2단계 인증(MFA) 정책 — 계정별 필수 지정 · 인증 앱 초기화 —

필수로 지정한 계정은 인증 앱을 등록해야 포탈을 쓸 수 있습니다 — 기한을 두면 그날까지는 로그인할 때 안내만 뜨고, 지나면(또는 기한이 없으면) 등록 화면이 먼저 뜹니다. DB 도 같은 규칙으로 막아(SQL 89) 비밀번호만 아는 사람은 데이터를 못 봅니다. 인증 앱 초기화는 폰을 잃어버린 사람용 — 등록을 지우면 다음 로그인은 비밀번호만으로 되고(필수면 다시 등록 화면), 본인에게 알려 주세요.

— 코드 관리 — 상태·채널·서비스 같은 선택 목록 (포탈 화면 · 데이터 점검 · DB 검증이 모두 이 목록을 봄) —

값을 숨기면 새 입력에서 고를 수 없고 데이터 점검이 «목록에 없는 값»으로 잡지만, 이미 그 값인 행은 그대로 둡니다(다른 열 수정도 가능). 순서는 ↑↓ 로. 저장하면 포탈을 쓰는 모든 사람에게 다음 데이터 로드부터 적용됩니다(본인은 즉시).

— AI 사용 비용 (Anthropic) —

Anthropic은 잔액 조회 API가 없어 «충전액 − 충전일 이후 사용액»으로 잔여를 추정합니다 (사용액은 Cost API 실측 · 최대 5분~수 시간 지연). 콘솔에서 자동 충전(auto-reload)이 켜져 있으면 충전분이 반영되지 않아 실제 잔액보다 적게 나옵니다 — 그때는 충전액 칸을 «누적 충전 합계»로 고쳐 주세요. Edge Function admin 의 Secrets에 ANTHROPIC_ADMIN_KEY(sk-ant-admin…, 콘솔 Settings→Admin keys) 추가 필요.

변경 이력

데이터 입력·수정

모든 변경은 DB의 변경 이력(change_log)에 기록됩니다.

추가 구매는 원계약에 매달린 부속 계약으로 저장됩니다 — 고객사·서비스·채널·파트너는 원계약을 그대로 따르고, 고객사 수·LIVE·계약 수·해지에는 세지 않으며 MRR에만 더해집니다.
연장은 기존 계약 한 줄에 «연장 n회»로 쌓입니다 — 별도의 재약정 행을 만들지 않으므로 해지율·계약 수에 영향이 없습니다.

한 달만 고치려면 시작월·종료월을 같은 달로. 그 구간만 바뀌고 앞뒤 달은 그대로입니다.

고객사 마스터를 바꾸면 계약·월 매출·해지·LIVE·사업영역·증감 화면이 모두 새 이름으로 바뀌고, 이름을 글자로 따로 가진 표(LIVE 명단·LG U+·임대 장비 신청/현황·OI·MDR 운영·PoC·주간보고·비즈포탈 대조·인바운드)도 한 번에 같이 바뀝니다. 변경 이력(change_log)에 기존 사명이 남습니다.
